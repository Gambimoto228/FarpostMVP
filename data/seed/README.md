# seed

JSON-файлы для наполнения локальной БД. Имя файла = имя сущности (`houses.json`, `documents.json`).

Правила:

- каждый файл — JSON-массив объектов;
- схему сущностей задаёт задача про модель данных (DD-XX), до неё файлы не добавляем;
- грузится командой `cd backend && uv run seeded`.

Пока каталог пуст: загрузчик напечатает «загружать нечего» и выйдет с кодом 0.
