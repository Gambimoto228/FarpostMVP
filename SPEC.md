# Python library contract

## Scope and boundaries

Python 3.12+ library, with a future thin FastAPI adapter. No HTTP application, database, external requests, dataset file loader, address inference or data collection. `core` owns process configuration and explicit logging setup. `contract` owns dataset 1.0 validation, immutable DTOs and sanitized errors. `rating` owns pure calculations and reports; it imports only the public dataset/error contracts, never `core` or FastAPI.

## Configuration

`core.config.Settings` is a frozen Pydantic Settings model. Only `log_level` (CRITICAL/ERROR/WARNING/INFO/DEBUG, default INFO) and `log_file` (Path or None, default None) exist. Explicit arguments override environment, which overrides UTF-8 `.env` in the working directory, which overrides declared defaults. Environment names are uppercase field names. Unknown dotenv/constructor fields fail; unrelated environment variables are ignored. Empty/whitespace-only log_file means None; empty or invalid log_level fails. `get_settings()` lazily caches the first successful instance; failed construction is not cached. `SettingsRefused` exposes only originating error class, declared field/code pairs and undeclared error count, never input values or original exception chains.

`core.logging.setup_logging(settings=None)` explicitly initializes a named `domdose` logger, idempotently. None log_file selects a console handler; a path selects UTF-8 file output. It does not modify the root logger or global record factory. Imports create no handlers or files.

## Dataset contract

The packaged `contract/dataset.schema.json` is an unchanged copy of the supplied dataset 1.0 schema. Treat it as JSON Schema Draft 2020-12 with format checking. `dataset_schema()` returns a fresh copy. `read_dataset(Mapping | str | bytes) -> Dataset` is the single public structural and semantic validation door. UTF-8 JSON only; reject duplicate object keys and nonfinite JSON numbers. DTOs use Pydantic v2, forbid extra fields, retain required nullable fields, use immutable tuples and frozen nested models, and serialize back to JSON-compatible arrays/dates/timestamps. JSON Schema integral numeric values such as 2.0 remain legal integer inputs; booleans are not integers.

`ContractRefused.issues` is a tuple of `ContractIssue(code, path)` with machine-readable codes and field/index paths. No raw input values or unrecognized object keys appear in public errors; use `$extra` for an unknown key. Structural invalid input is refused before semantic processing. Unknown/null facts and empty datasets remain legal: absence of data is not malformed data.

Semantic invariants: unique source/house/event IDs; valid references; nonempty event.sources; unique house/source references within an event; timestamps explicitly offset +10:00; ordered inclusive dataset period and known source date ranges; event start local date inside period; finite nonnegative durations/counts; city total None or positive; affected count at most city total when both known; endpoints at or after start. `actual` basis requires actual endpoint and matching duration; `planned` requires absent actual endpoint, known planned endpoint and matching duration; `unknown` requires duration None, without inferring missing duration from synthetic midnight or endpoints. Duration agreement tolerance is 0.005 hours, half of the 0.01 hour rounding step of the published source: a stored duration must agree with its endpoint within that tolerance, and the calculation uses the stored value. Do not enforce collection quotas, ID spelling, service eligibility, season or quality assumptions as schema facts.

## Approved rating method

Policy ID: `rating_observed_exposure_proxy_v1`. The report always represents observed, approximate results, never certified reliability.

`rating.evaluate(dataset: Dataset | Mapping | str | bytes, request: CalculationRequest) -> CalculationReport`. Request carries unique existing target_house_ids, explicit end_exclusive timestamp +10:00 and policy_version. No implicit clock. Reports retain method/window/category metrics, baselines and denominators, ratios/penalties/scores, effective weights, limiting categories, source-span indicators, limitations and structured diagnostics. Do not mutate input or round core results. Unknown policy and malformed request are typed contract refusals. Insufficient facts return a partial report, not an unexpected exception.

Window W=[end_exclusive-30 days,end_exclusive). Count each event intersecting W once; hours and maximum use clipped intersection duration. Heating uses W intersect [heating_season_start,infinity), without extrapolation. Before season heating is not applicable; unknown season makes central heating unavailable. Do not reclassify heating into hot water. Unknown timing must not be inferred; uncertain overlap yields unavailable affected metrics. Period/source spans outside W are diagnostics, not automatic complete observation claims.

Event weight w: emergency=1, planned=0.4, unknown=unavailable. MVP mass heuristic: scope in {district,city}. Apply 0.5 once when mass OR force_majeure. Group alone is not mass. For an exactly linked house: F=sum(w), H=sum(w*d), M=max(w*d), empty known set=0. Additive event hours are not a union of overlapping outages. Planned endpoint duration is marked estimated. A relevant range/street link makes the affected category unavailable; never treat ambiguity as no outage. Null duration can leave frequency known but hours/maximum unavailable. Never infer city affected count from sample links or addresses.

City N=meta.city_houses.total includes all city MKD, including houses with no observed event. B_F=sum(n*w)/N; B_H=sum(n*w*d)/N. Any applicable unknown n/weight/duration makes the respective baseline unavailable, not a silently truncated complete-case calculation. Proxy Q_M=sum(n*w*d)/sum(n) is mean weighted duration over house-event exposures, NOT mean individual maximum over all houses. Zero-event houses are absent from Q_M; repeated events create repeated exposures. Its bias relative to the true mean maximum has no guaranteed direction. Empty known journal yields zero baselines/proxy with NO_OBSERVED_EVENTS; unknown inputs do not yield zero. Always report PROXY_BASELINE_USED and its denominator/method.

Penalty p(r): piecewise linear in log2(r) through (1,0),(2,0.33),(4,0.67),(8,1), clipped to 0 at r<=1 and 1 at r>=8. x=b=0 gives p=0; x>0,b=0 is inconsistent and unavailable; unknown b is unavailable. Category score R=1-(0.4*pF+0.4*pH+0.2*pM).

Category weights: electricity=0.30, cold_water=0.25, heating=0.25, hot_water=0.20. Only central and seasonally applicable categories enter the score; individual/none are excluded, remaining weights normalized. Unknown service eligibility or any unavailable eligible category yields overall None. No applicable categories yields not_applicable. Otherwise overall=min(weighted mean,min(category scores)+0.25).

Source covered_from/covered_to describe declared spans, not continuous coverage or confidence. Return union spans/gaps/unknown dates and original limitations without deriving a certified state or coverage percentage. Runtime passport attributes, sample quotas and control status do not influence formulas.

## Public report details

CalculationRequest accepts immutable tuples or JSON arrays of unique nonempty target IDs; direct construction requires datetime, JSON accepts an ISO timestamp. `evaluate` also accepts a request Mapping through the safe validation door. Constructor validation is Pydantic ValidationError; public evaluation wraps malformed requests in ContractRefused with INVALID_REQUEST, UNKNOWN_HOUSE or UNKNOWN_POLICY issues and request field/index paths. Dataset DTO inputs are revalidated through read_dataset, not treated as a semantic-validation bypass.

Category order is electricity, cold_water, heating, hot_water. Output house order follows requested IDs. Effective weights include all known central, seasonally applicable categories, even when their scores are unavailable; limiting_categories are populated only when all applicable scores are known. A ratio at x=b=0 is None (undefined), but its penalty is zero. Empty category journal gives zero observed metrics and NO_OBSERVED_EVENTS. Zero exposure denominator gives proxy zero by explicit convention; a positive target metric against zero baseline is inconsistent. `estimated` means a relevant known duration uses a planned endpoint (including the city baseline); planned kind alone does not imply an estimated time.

Report source_spans is four SourceSpan records: type, intervals, gaps, unknown_source_ids. SourceInterval start/end are inclusive dates. Union and gaps are computed from declared source dates clipped to the window's calendar dates; they are not verified continuous observation. Report limitations retain the original order and text without adding generated prose. Diagnostics use stable codes, field/index paths and event/house ID tuples: WINDOW_OUTSIDE_DATASET, AMBIGUOUS_MATCH, UNKNOWN_DURATION, UNKNOWN_KIND, UNKNOWN_OVERLAP, UNKNOWN_AFFECTED_COUNT, BASELINE_UNAVAILABLE, BASELINE_INCONSISTENT, HEATING_SEASON_UNKNOWN, SERVICE_UNKNOWN, PLANNED_DURATION_USED, SOURCE_COVERAGE_UNPROVEN, NO_OBSERVED_EVENTS, PROXY_BASELINE_USED. Uncertain overlap (start before window and no reliable end) makes affected frequency/hours/maximum unavailable. Start known inside window with unknown duration leaves frequency computable.

## Acceptance

Frozen synthetic datasets, not invented real observations. Independent tests before implementation. Validate JSON/schema parity and roundtrip, safe errors, references/types/times/durations, settings precedence/cache, explicit logging, dependency directions, 30-day and season boundaries, null/ambiguous inputs, event weights and single modifier, city population including zero houses, exposure proxy denominator, exact penalty knots/midpoints, category eligibility/renormalization/cap, no input mutation or hidden I/O. Numeric comparisons atol=1e-9; diagnostic ordering deterministic. Mutants must be caught: null-to-zero, sample population denominator, Q_M replaced by B_H or a differently weighted denominator, double discount, silent omission of an unavailable eligible category.
